# 고대 국가 제1장 — 한강에서 바다까지 (v54)

## 구현 범위와 역사 자료

v53 생활 공간 위에 1~3번만 구현한다. 4~7번은 아래의 후속 계획이며 현재 플레이·보상·역사 사건을 활성화하지 않는다. 4세기 전체는 아직 미완료이므로 다음 세기/고대 국가 완료를 열지 않는다.

확인한 국사편찬위원회 자료:

- [재미있는 초등역사 · 삼국의 한강 유역 쟁탈](https://contents.history.go.kr/mobile/eh/view.do?code=eh_age_10&levelId=eh_r0116_0010): 한강 유역의 농경·교통 이점.
- [한국사 연대기 · 근초고왕](https://contents.history.go.kr/mobile/kc/view.do?code=kc_age_10&levelId=kc_n100610): 재위346~375, 남쪽 진출,369치양/371평양성/372동진 외교의 후속 연결.
- [재미있는 초등역사 · 영산강 유역의 마한 유적](https://contents.history.go.kr/mobile/eh/view.do?code=eh_age_10&levelId=eh_r0045_0010): 마한 통합 시기의 여러 해석. 모든 마한 세력이369년 한꺼번에 사라졌다고 단정하지 않는다.
- [신편 한국사 · 백제와 중국](https://contents.history.go.kr/mobile/nh/view.do?levelId=nh_006_0040_0010_0010):372동진과의 공식 관계.

기존 프로젝트의 교과서·지도서 자료 검토 기록은 ancient-design.md에 보존한다. 이번 작업에서는 새 PDF 원본이 제공되지 않았다. 나루지기·견본 꾸러미·화물 배치·거래 문제·경로·왕의 대사는 게임용 창작이다. 실제 교역로·선박 구조·왕 복식·발언을 복원했다고 주장하지 않는다. 근초고왕이 나루터를 직접 방문한 장면은 없다.

## QUEST 1 구현

이야기 책상의4세기 시작/지도 확인→자기 마을 교역 담당자(16,9)→전용 꾸러미→기존 동쪽 여행길/방향별 안내→한강 나루지기(10,8). 전달 후 강·배·곡식 짐3개를 그림에서 관찰하고 현장에서 기록하면 완료한다. 꾸러미는 `ancient.baekje4c.parcel`이며 일반인벤토리·판매/보관에 들어가지 않는다. 전달 자체를 저장하여 종료 후에도 잃어버리지 않는다.

담당자: “이 곡식 견본 꾸러미를 나루지기에게 전해 줄래?”
나루지기: “마을에서 보낸 꾸러미구나. 잘 가져왔어!”
관찰: “넓은 한강 주변은 농사짓기 좋고, 강은 물건을 옮기는 길이 되었어.”

## QUEST 2 구현

나루지기에서 시작. 원형 토큰/직사각형 배 대신 나무판·선수/선미·선체 그림자 있는 SVG목선, 매듭/곡식 문양 자루, 토기, 나무 상자 그림을 쓴다. 부두·흐르는 물결 배경. 플레이어를 별도의 대체 토큰으로 표시하지 않는다. 클릭/터치 선택→왼쪽·오른쪽 놓기→기울기/실제화물표시→재배치→출항. 키보드 Tab/Enter/Space로 같은 네이티브 버튼을 사용할 수 있다.

| 라운드 | 화물 무게 | 해결 예 |
|---|---|---|
|1|항아리2,상자2|2:2|
|2|큰자루3,항아리2,작은자루1|3:2+1|
|3|큰자루3,항아리2,상자2,작은자루1|3+1:2+2|

모든 화물 배치+무게차≤1이 판정이며 숫자와 동일한 무게를 표시한다. 배 기울기±7도, 놓을 때짧은이동, 출항 시화물과배가 함께 강으로 이동한다. 오답 때손실 없이 재배치·라운드별 도움말. 닫기/재접속 후 같은 라운드/좌우 배치로 이어진다. 최종 출항 후 완료를 확인하면25엽전/평판2/경험치12. 개인 수레와 무관하다.

## QUEST 3 구현

나루지기 북쪽의 남쪽 상인(10,5)에 직접 접근한다. 실제 생활 판매·교환 상인이나 운송 수령인과 다른 좌표/ID다. 각 세트에 SD상인3명과 가진 것/필요한 것 그림이 나온다. 두 명을 선택하고 교환 확인. 서로 원하는 경우만 성립한다. 세 교환(곡식↔항아리,상자↔천,작은곡식↔항아리)을 해결한다. 맞지 않으면 한 문장 힌트,생활재산 손실 없음. 물품이 두 상인 사이로 이동한다.

다음 두 상황: 강으로 이어진 곳에 많은 무거운짐→물길; 물길이 닿지 않는 내륙마을→육로. 작은 게임지도에서 목선 또는 팔·다리 있는 상인이 화물과 함께 이동한다. 걷는상인은 SVG내부 다리2프레임 움직임을 사용한다. 정확한4세기 노선이라고 주장하지 않는다.

궁정 장면은 나루에서 화면 전환으로만 보여 준다. 근초고왕 전용SD(얼굴/관모/겉옷/띠/팔/바지/신발/그림자)를 사용한다. “한강을 오가는 사람들이 늘고 있구나. 남쪽 여러 지역과도 관계가 넓어지고 있어.”는 게임 창작대사다. 남쪽 진출을 설명하되 한 번의 교역으로 마한 통합이 끝났다고 하지 않는다. 기록 완료→QUEST4 대기.

# 고대 국가 1단계 · 자료와 확장 계약

## 이번에 실행되는 범위

여러 나라의 성장 완료 → 고대 국가 해금 → 기록 마당 오프닝 → 네 건국 이야기의 탐색·수집·전달 → 두 확인 문제 → 나라 선택/확정 → 해당 마을 도우미 → 내 거처 → 4세기 시작 → 별도 역사 지도. 21개 실행 단계이며 마지막 대기 슬롯은 시대 전체 완료로 처리하지 않는다.

고구려·백제·신라 선택은 능력치나 획득률을 바꾸지 않는다. 필수 건국 이야기는 공통이고 마을·집·도우미·지형·일부 대사만 다르다. 가야는 시작 국가가 아니다. 건국편의 한강 장면과 정착 이후 한강 맵은 같은 `ANCIENT_HAN_TERRAIN`을 공유하며 각각 이야기 장면과 세기별 생활 지역으로 사용한다.

## 기준 자료

사용자가 제공한 다음 수업 PDF 4종을 모두 읽었다. 원본 PDF를 공개 저장소에 재배포하지 않는다.

- 「5-2-1-2_7-8. 고대국가는 어떻게 발전했을까요」 월림: 건국 인물·지역·설화의 의미, 4~6세기 성장 흐름.
- 「5-2-1-2_10. 고대 국가 사람들은 어떻게 살았을까요」 조조쌤: 귀족·평민·노비, 옷감·집·생활 도구·진대법 등 후속 생활 슬롯.
- 「5-2-1-2_9. 고대국가는 주변 나라들과 어떻게 교류했을까요」 월림: 중국·일본·서역과의 교류, 후속 항구·시장·교역 기록.
- 「5-2-1-1_11-12. 고대국가는 어떤 문화를 꽃피웠을까요」 루체12: 나라별 유물·문화의 후속 제작 기준.

### 설화와 사실

주몽·박혁거세·김수로의 알/하늘/동물 장면은 `[건국 이야기]`와 “옛사람들은 … 전했어”로 구분한다. 김수로는 금관가야 건국 인물이며 가야는 여러 나라로 이루어졌다고 밝힌다. 모임용 가지·끈 수집은 게임 활동이고 역사적 의식의 재현이라고 주장하지 않는다.

### 인물·복식·거처

일반 도우미는 기존 농부·상점 주인·노인 PNG를 재사용한다. 투명 여백을 제외한 원본 종횡비를 유지해 같은 사람 체형으로 표시하며, 같은 마을의 상인은 도우미와 다른 기존 얼굴을 쓴다. 주몽·온조·박혁거세·김수로는 기존 픽셀/SD 인물 계열을 참고한 전용 투명 PNG다. 얼굴은 게임용 재구성이며 저고리/겉옷·바지·허리띠·신발의 기본 형태만 자료 범위에서 단순화했다. 창건 시기의 정확한 왕복이나 관등별 복색을 확인했다고 주장하지 않는다. 후대 금관·관료 복색을 앞선 건국 시기에 적용하지 않는다. 나라별 거처 색과 마당 차이는 게임의 시각적 구분이며 역사적 공식 색 체계가 아니다. 세 거처의 크기·실내·보관·기능은 같다. 자산과 제작 지침은 [인물·거처 자산 기록](ancient-assets-v44.md)을 따른다.

후속 왕인 근초고왕·광개토대왕·장수왕·진흥왕은 `ANCIENT_KINGS`에 등록했으나 `art:null, available:false`다. 본 퀘스트를 만들 때 나라/연대가 맞는 복식·관모·띠·신발 자료를 다시 확인하고 전용 자산을 제작한다. 자료가 부족한 부분은 재구성이라고 밝힌다.

### 지도

사용자가 제공한 백지도 JPG 세 장을 그대로 사용한다. 4세기는 백제 전성기, 5세기는 고구려 전성기, 6세기는 신라 전성기다. 기존 직접 그린 지도와 영역·경로를 제거했다. 원본 파일의 바이트는 바꾸지 않았다.

후속 요청에 따라 원본의 네모 테두리 `[x=103, y=241, 너비=1242, 높이=1704]` 안쪽만 CSS로 표시한다. 바깥 제목·흰 여백을 제외하며 지도의 종횡비·경계·문자·점선은 유지한다. 제목은 화면에 별도 표시한다. 확대/스크롤은 같은 잘라낸 표시 범위를 사용한다.

이동 버튼·현재 위치는 원본 이미지 위의 별도 투명 오버레이다. 좌표도 잘라낸 범위에 맞게 환산한다. 거점 표시는 게임의 장소이며 역사적 정확한 국경·주소를 추가로 주장하지 않는다. 미개방 국가 잠금과 방문한 장소 이동 규칙은 유지한다.

## 코드 확장 지점

| 목적 | 계약 |
| --- | --- |
| 챕터/퀘스트 | `ANCIENT_CHAPTERS`에 주제·순서·세기·후속 슬롯·마무리 퀴즈 수를 선언한다. 실제 퀘스트가 등록되기 전 `ready:false`를 유지한다. |
| 진행 | 기존 `REGIONS[].quests` 및 `advance`를 사용한다. `ancientEventAllowed`는 수집·퀴즈·선택 선행조건을 검사한다. |
| 다음 세기 | 실제 챕터 퀘스트 완료를 확인하는 `completeAncientChapter`가 다음 데이터의 세기로 연결한다. 1단계 일반 플레이는 4세기 진입까지만 열린다. |
| 지도/한강 | `ANCIENT_MAPS`와 `ancientWorld`의 불변 오버레이로 NPC·표식·건물 장식·대사·귀환 목적지를 바꾼다. 원본 공용 맵을 수정하지 않는다. |
| 거처 | `ancient.home`의 보관 물품·전시 ID·확장 ID를 시간 전환 시 보존한다. `ANCIENT_EXHIBITS`에 자료 기반 문화 기록을 등록한 뒤 전시를 추가한다. 현재 전시는 비어 있다. |
| 미니게임 | `ANCIENT_ACTIVITIES`는 문화 관찰/교류/7세기 러너의 미구현 슬롯이다. 구현할 때 공유 `INTERACTION_QA`와 실제 완료 이벤트를 함께 등록한다. |
| 관리자 | 모든 퀘스트의 `qa`에 선택 퀘스트 직전과 공통 15개 상태를 등록한다. 공유 `prepareContentQA`와 기존 `adminJump`를 사용한다. 시험은 원본 학생 저장과 분리된다. |
| 말 | 기존 말 획득·탑승·속도를 유지한다. 소유한 거처 앞 한 자리와 플레이어 탑승 상태 사이에서 한 마리만 이동하며 전역 `horseParked` 기본값은 `false`다. 실내 입장 시 세워두고 나라·세기·새로고침 뒤에도 보존한다. 공유 시험 목록에 말 상태 4종과 세 거처 바로가기를 함께 등록한다. |
| 저장 | `saveVersion:3` 및 개인 코드 계약을 유지한다. `ancient`가 없는 옛 저장은 안전한 기본값을 받으며 5번 시대 완료 여부로만 해금한다. |

## 후속 제작 원칙

- 가야와 철, 생활, 문화, 교류, 7세기, 신라 통일, 통일신라·발해는 현재 미구현이다. 외국 대형 맵이나 빈 대형 가야 지역을 만들지 않았다.
- 문화재는 제공 PDF와 실제 사진·박물관 자료를 먼저 확인한다. 고분벽화, 연가7년명 불상, 무령왕릉, 백제금동대향로, 신라 금관·첨성대, 가야 판갑옷·말 갑옷·덩이쇠·굽다리접시의 실제 실루엣·재질·대표 구조를 보존한다.
- 백제금동대향로의 용·연꽃·산봉우리·봉황 같은 학습 특징을 단순화 과정에서 삭제하지 않는다. 지금은 이 유물 그래픽을 제작하거나 전시하지 않았다.
- 학습 → 이동/활동 → 확인 퀴즈의 간격을 둔다. 퀴즈 장소·NPC·직함·제목·직전 대화·상호작용 버튼에 정답을 다시 노출하지 않는다. 세기별 실제 챕터에는 짧은 중간 확인과 마무리 2문제를 연결한다.
- 전쟁은 대량 처치 목표 중심으로 만들지 않는다. 전령·군량 수송·대피·문서 전달·탈출 등으로 체험한다. 러너 게임은 1단계에서 구현하지 않는다.


## v51 세계관·지리·한강 사건 계약

개인 거처와 역사적 영토는 서로 다른 기록이다. 고구려 거처는 북쪽 본거지의 가상 생활마을, 백제 거처는 남쪽 내륙의 가상 생활마을, 신라 거처는 경주 주변 생활마을이다. 특정 실제 마을·정확한 주소를 주장하지 않는다. 백제 마을 물길은 작은 하천이며 한강이나 한성으로 안내하지 않는다. 모든 역사적 한강 활동은 별도 `ancient-han`에서 한다. 475년 한성 함락 때문에 백제 플레이어의 집·마당·재산을 삭제하거나 다른 나라로 바꾸지 않는다.

마을 동쪽 출구에 접근하여 여행 안내를 확인한 뒤 한강으로 이동한다. 북쪽에서 남쪽으로/남쪽 내륙에서 북쪽으로/경주 주변에서 서북쪽으로 가는 서로 다른 길을 압축 표현한다. 실제 역사 경로·거리의 복원은 아니다. 한강의 귀환 출구는 항상 선택 나라 마을로 이어진다. 출구 ID/좌표/운송 목표를 유지하여 이미 진행 중인 운송도 끊기지 않는다. 운송 중 지도 빠른 이동과 말 탑승 제한은 기존 계약을 따른다. 여행 확인 버튼도 해당 출구 근처인지 다시 검사한다.

`ancient.century`는 챕터/대표 전성기 지도 선택이며 영토 변경 스위치가 아니다. 독립 `ancient.history = {revision:1,phase,events}`가 현재 한강 지역을 결정한다.

| phase | 현재 한강 | 완료 사건 |
|---|---|---|
| baekje-4 | 4세기 백제 중심 | 없음 |
| baekje-pre475 | 5세기 한성 함락 이전 백제 | 없음 |
| goguryeo-post475 | 475년 이후 고구려 | hansong-475 |
| goguryeo-pre551 | 6세기 551년 이전 고구려 | hansong-475 |
| alliance-551 | 백제 하류·신라 상류 | hansong-475, han-551 |
| silla-post553 | 553년 이후 신라, 하류 포함 | 세 사건 모두 |

후속 개발자는 실제 구현된 퀘스트 ID를 `HAN_EVENT_QUESTS`에 등록한다. `syncAncient`에서 완료 퀘스트와 선행 사건을 확인한 `completeHanHistoricalEvent`만 사건을 반영한다. 현재 등록은 비어 있으므로 학생은 미래 사건을 해금할 수 없다. 전반 시점(5세기 이전/6세기 이전)은 해당 실제 챕터의 시작 조건을 검사하는 후속 전환에서 설정한다. 단순 `setAncientCentury`는 역사 상태에 손대지 않는다. 관리자 `previewHanHistory`는 별도 시험 세션에서만 사용한다.

v50.1 저장에 history가 없으면 기본 `baekje-4`를 추가한다. 과거 관리자 지도 조회나 세기 값만으로 475/551/553년 완료를 추정하지 않는다. 엄격한 phase/events 조합 검증을 유지한다. 기존 saveVersion3/개인 코드/JSON 저장 계약, home 및 소유 기록은 그대로다.

현재 상태는 지역명, 주민·운송 수령인 외형, 경비병 옷과 창, 나루 표식, 보관채 표식, 주민 대사를 결정한다. 551년은 두 표식과 서로 다른 하류/상류 수령인으로 구분한다. 색과 깃발 도안은 게임의 시각 구분이며 역사적 공식 국가색·국기로 주장하지 않는다. 신규 경비병은 기존 농부 체형과 얼굴에 작은 겉옷/창을 더한 SVG다. 원본 백지도 JPG 세 장과 자르기/확대 비율은 변경하지 않는다. 지도 설명에서 대표 전성기와 현재 사건 상태를 따로 표시한다.

평판은 생활 성장과 사람들의 신뢰이며 역사적 신분/골품이 아니다. 평판으로 골품을 승격하는 퀘스트를 만들지 않는다. HUD는 현재 고대 국가이고 나라 선택 완료한 경우만 표시한다. '나' 메뉴는 나라 선택을 마친 기록이 있는 경우 생활 평판을 보여 준다. 기존 5단계·100점 상한·보상량은 유지한다.

역사 사실 확인: [국사편찬위원회 우리역사넷 · 삼국의 한강 유역 쟁탈](https://contents.history.go.kr/mobile/eh/view.do?levelId=eh_r0116_0010). 사용자 지정 475/551/553년 사건 순서를 따르며 실제 메인퀘스트·7세기 세계 변화는 이번 범위에 포함하지 않는다.

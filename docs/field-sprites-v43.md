# 산적·호랑이 필드 그림 조정

- 산적 새 자산: `dist/assets/enemies/bandit-v43.png`. 기존 그림은 보존했다. 내장 이미지 편집 도구로 산적 원본을 편집했고 플레이어 그림을 체형·그림체 참고로 사용했다.
- 편집 요청: “머리/머리카락/스카프 비중을 줄이고, 허리와 긴 두 다리가 보이는 건장한 사람 체형. 검은 머리띠·붉은 얼굴 가리개·베이지 상의·갈색 바지·장화·정면 자세와 기존 픽셀 그림체 유지. 가로 압축 금지. 단독 전신 투명 배경.” 첫 결과에서 머리 비중을 약 18% 더 줄인 두 번째 결과를 채택했다.
- 산적 실제 실루엣 높이 69px, 정예 71.76px. 기본 플레이어 실루엣 약 62.6px 대비 약 1.10/1.15배. 새 원본의 투명 여백을 제외한 비율 그대로 그려 폭은 약 27.4/28.5px다. 기존 필드의 58px 폭과 짧은 다리 조합을 제거했다.
- 호랑이는 기존 원본을 유지한다. 투명 여백을 제외한 원본 비율 그대로 76.6×91px, 정예는 1.03배로 표시한다. 전신 앞뒤 길이 약 1.45배(정예 약 1.50배). 앞발이 기존 월드 좌표에 닿는다. 위에서 비스듬히 본 원본이라 세로 전신 길이에 꼬리·몸통·앞발이 포함되고 어깨 높이와는 다르다.
- 그림 전용 `dist/field-sprites.js`의 크기는 그리기에서만 참조한다. 전투 거리 0.65칸, 조사 거리 1.65칸, 몬스터 좌표·정예 능력치·드롭·재출현·저장은 그대로다. 기존 NPC/늑대/곰 그림과 표시 설정도 유지했다.
- 검수: `scripts/verify-field-sprites.mjs`에서 실제 게임 그리기 호출·동일 비율 확대·일반/정예 산적의 상한·호랑이 비율, 1.2칸 조사 버튼, 0.66칸 전투 미시작/0.64칸 시작, 충돌 범위 및 기존 HP/공격력을 확인한다. 가상 기록만 사용한다.

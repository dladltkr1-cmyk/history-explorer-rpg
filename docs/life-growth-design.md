저장 버전3·lifeRevision2·개인 코드/서버 계약은 그대로다. 새 필드나 초기화가 없다. 집1~4,작물/씨앗,엽전/재료,도구,18가구/배치/등잔,평판,부탁/완료/운송,보관/말/낚싯대,역사 상태를 보존한다. 커진 맵의 좌표 검증은 실제 w/h를 사용한다. 기존 실내 저장은 같은 맵에서 이어지고 출구만 새 거리로 연결한다. 새로고침/서버 로딩은 같은 validate 경로를 거친다.

새 그래픽은 기존 상점12종과 가구/나무 자산을 재사용하고 교역 노점·수레 바퀴·담장·그루터기·수풀 SVG5개만 보완한다. `regions/life-districts.js`와 `life-terrain.js`가 거리/숲의 건물 간격·길·나무 군집·재료 소품을 정의한다. 원본 역사 지도 JPG와 v52 가구18종의 바이트/표시크기/효과는 유지한다.

관리자 공통 상호작용의 v53 생활 공간 시험에서 세 나라,9개 접근 위치,네 실내,채집 가능/대기/이전 기록과 기존 성장/가구/두 운송 시험을 사용한다. 모든 준비는 기존 관리자 격리 세션이며 학생 원본/개인 코드에는 쓰지 않는다. 신규 `verify-life-spaces.mjs` 및 `verify-life-spaces-ui.mjs`는 원격/잔여콜백 거부,42개 걸어서 접근 목적지,저장 호환과3나라×3화면 생활 흐름을 검사한다. 실제 공개 브라우저와 물리적 태블릿 검수 범위는 업데이트 보고서에 따로 기록한다.


현재 구현값이다. 역사 본편·다음 시대가 붙어도 `ancient.home`의 소유 기록을 이어받는다. 평판은 역사적 사회 신분이 아니며 엽전은 게임용 가상 화폐다.

`saveVersion:3`, 개인 코드·서버 전송 계약은 그대로. `lifeRevision:2` 및 `ancient.home.commerce` 추가. commerce에는 revision, orders[{id,key}], nextId, completed, history(최근30), focus, tools, legacyBulkHarvest, cart{owned,commissioned,active:{id,key,country}|null,nextId,completed}를 저장한다. 보상/요구량은 저장된 숫자를 신뢰하지 않고 정의에서 계산한다. 완료 카드 ID가 즉시 교체되므로 이중 클릭/같은 저장 복원 후 이전 ID 재납품이 실패한다. v48.1 lifeRevision1은 집/씨앗/작물/배치/재산을 보존하고 기존 모두 수확 편의를 legacyBulkHarvest로 유지한다. 시간 역행 시 성장은 음수가 되지 않고 수확은 칸을 비워 중복 지급을 막는다. 기기 시계 자체의 고의 변경 검증에는 향후 서버 기준 시간이 필요하다.

후속 스토리는 `meetsLifeRequirements`와 독립 해금 정의를 사용한다. 새 왕/4·5·6세기 본편/다음 시대 진입은 아직 만들지 않았다. 향후 시대 진입에서도 `ancient.home`을 초기화하지 말 것.

## v51 지리·역사 상태 분리 보완

나라별 개인 거처는 역사적 한강 맵과 떨어진 생활마을이다. 백제는 남쪽 내륙의 가상 마을, 고구려는 북쪽 본거지, 신라는 경주 주변이다. 집 1~4단계·밭/논·작물의 실제 시간·18종 꾸미기·보관·도구·수레·평판·부탁/운송 실적은 `ancient.home`에 유지한다. 한강 역사 상태는 독립 `ancient.history`이고 세기 지도나 정치적 변화 때문에 home을 초기화하지 않는다. 구체적 사건/후속 계약은 `ancient-design.md`의 v51 절을 따른다.

구매는 v50.1의 실제 마을 전문 상점 방문 원칙을 유지한다. v53에서 농사·수확은 마당, 제작은 마당 작업대, 조리는 집 화로, 배치/회수는 현 공간, 확장 조건은 목공소로 분리했다. 한강 여행 안내는 기존 마을 출구와 귀환길을 사용하며 운송 메뉴 순간이동·말/빠른 이동 우회를 만들지 않는다. 평판 수치는 생활 신뢰이며 귀족 신분이나 신라 골품을 바꾸지 않는다.


## v52 집 꾸미기 표현·사용 계약

18종의 ID·가격·조건·수량과 12개 고정 자리의 ID/해금 순서는 유지한다. `decor-spec.js`의 크기는 64px 타일 기준 월드 픽셀이며 화면 확대율을 별도로 적용한다. 전용 SVG 18종은 160×160 원본 내부의 바닥선149를 공유하고, 입체가구·바닥천·벽걸이의 깊이를 구분한다. 게임용 생활 재구성이며 실제 유물 문양의 정확한 복원을 주장하지 않는다.

`decor-ui.js`의 눈으로 꾸미기: 보유 가구 → 설치 가능한 자리 → 실물 크기 반투명 미리보기 → 놓기. 미리보기·선택 취소는 소유/배치/돈을 바꾸지 않는다. 이미 놓인 마지막 한 개는 위치를 옮기며 복제하지 않는다. 회수는 수량 차감이 없다. 기존 목록 배치도 같은 `canPlaceDecor` 검사를 사용한다. 새 대형 가구는 넓은 자리에 제한하지만, 구버전의 합법적인 배치는 검증에서 거부하지 않는다. 확장할 때 자리별 좌표가 새 방 크기에 맞춰 계산된다.

바닥천은 인물 아래, 입체가구는 발밑 y 기준으로 정렬한다. 높은 가구 뒤의 인물은 가구를 흐리게 해 가리지 않는다. 침구는 기본 잠자리를 대체하며 기존 보관함·화로·이야기 책상·출입문 기능은 남기며, v53에서 실내 생활 책상만 제거했다. 마당 자리는 집/농지/수레/작업대의 통로를 피한다.

저장 버전3과 생활 revision2를 유지한다. 새 `ancient.home.lamps`는 자리 ID→boolean 사전이며 구버전 누락 시 빈 사전으로 보완한다. 배치된 등잔만 키를 가질 수 있다. 교체/회수 시 정리, 이동 시 해당 등잔 켜짐 상태를 함께 이동, 집 확장 시 그대로 유지한다. 다른 자산·역사 상태와 분리한다.

누비 침구 휴식은 기존 집 휴식과 동일한 함수(`applyHomeRest`)를 호출한다. 최대 HP의40%까지 올리는 기존 기준과 기력20을 유지하며 반복해도 누적 회복되지 않는다. 침구 없는 기존 휴식은30% 기준이다. 앉기/그늘 쉬기는 보상·회복이 없다. 수확 진열은 기존 harvested 조회만 한다. 등잔은 작은 불꽃/국소 빛만 표시하며 자원·유지비가 없다. 자세는 현 캐릭터 커스터마이징 이미지를 사용하고, 이동/다른 창/취소 시 해제한다.

관리자 공통 상호작용 목록의 ‘집 꾸미기’에 세 나라×4단계,18종 보유,없음/일부/전체12자리,주요 사용,이전 형식 복원 시험을 제공한다. 기존 관리자 별도 세션만 사용하며 학생 원본/코드에 시험 결과를 쓰지 않는다. ‘전체’는18종 보유/현재 해금 자리 채움을 뜻하며 동시18개 설치가 아니다.
